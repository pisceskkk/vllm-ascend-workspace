# Performance evidence

Record every warmup and measured repetition, throughput, TTFT, TPOT, ITL and any app-specific metrics actually emitted. Preserve raw outputs and variance inputs. Record exact commit/submodule SHAs, model/weight identity, hardware and topology, device IDs, container generation, runtime/native hashes, workload configuration, timestamps, platform Run ID, and archive URL.

Do not compare a Jiguang result with a local result unless hardware, runtime, model, workload, warmup, and metric definitions are demonstrably equivalent. Jiguang remains an optional third-party archive, not a replacement for the local benchmark toolchain.
